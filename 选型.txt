游戏掌机第一版采购清单

目标方案：
STM32H743 + 320x240 TFT 屏 + microSD 读取 GB ROM + 按键输入 + 后续加入音频和电池供电。

一、主控开发板

1. STM32H743 开发板
   推荐型号：
   - NUCLEO-H743ZI2
   - WeAct Studio STM32H743VIT6 Core Board
   - 正点原子 Apollo STM32H743 开发板

   建议：
   第一版优先买开发板，不要直接画自定义主板。NUCLEO-H743ZI2 最稳，资料多；WeAct H743VIT6 更小，更接近掌机体积。

2. ST-Link 调试器
   推荐型号：
   - ST-LINK/V2
   - STLINK-V3MINIE

   说明：
   如果买 NUCLEO-H743ZI2，板上自带调试器，可以先不单独买 ST-Link。

二、显示屏

1. 320x240 TFT 屏
   推荐型号：
   - ILI9341 2.8 英寸 320x240 SPI TFT 模块
   - ILI9341 2.8 英寸 320x240 8080 并口 TFT 模块

   建议：
   第一版可以买 SPI ILI9341，接线简单、资料多。后续如果刷新率不满意，再换 8080 并口屏。

2. 屏幕排线/杜邦线
   推荐：
   - 公对母杜邦线
   - 公对公杜邦线
   - 面包板跳线套装

三、存储

1. microSD 卡模块
   推荐型号：
   - SPI microSD Card Module，支持 3.3V

2. microSD 卡
   推荐：
   - SanDisk / Samsung / Kingston 16GB 或 32GB microSD

   说明：
   GB ROM 很小，容量不需要大。优先选稳定品牌。

四、按键输入

1. 轻触按键
   推荐规格：
   - 6x6x5mm 轻触开关
   - 6x6x4.3mm 轻触开关

   数量：
   - 十字键：4 个
   - A/B：2 个
   - Start/Select：2 个
   - 预留 L/R、菜单、复位：3 到 5 个

2. 摇杆帽/按键帽
   推荐：
   - Game Boy 风格硅胶导电胶按键套件
   - 轻触开关按键帽

   建议：
   原型阶段先用轻触开关，外壳版再考虑硅胶导电胶。

五、音频

1. I2S DAC 模块
   推荐型号：
   - MAX98357A I2S 功放模块
   - PCM5102A I2S DAC 模块

2. 喇叭
   推荐规格：
   - 8 欧 1W 小喇叭
   - 8 欧 2W 小喇叭

   建议：
   第一版可先买 MAX98357A + 8 欧 1W 喇叭，接线简单。

六、电源

1. 锂电池
   推荐规格：
   - 3.7V 2000mAh 锂聚合物电池
   - 3.7V 3000mAh 锂聚合物电池

   注意：
   必须购买带保护板的电池，避免过充、过放、短路风险。

2. 充电管理模块
   推荐型号：
   - TP4056 Type-C 充电模块，带保护板版本

3. 升压/降压模块
   推荐型号：
   - MT3608 升压模块
   - MP1584 降压模块

   建议：
   开发板阶段可以先用 USB 供电。电池供电等程序跑通后再接入。

4. 电源开关
   推荐规格：
   - 小型拨动开关
   - 自锁电源开关

七、外壳与结构

1. 原型固定材料
   推荐：
   - M2 铜柱套装
   - M2 螺丝套装
   - 亚克力板或洞洞板
   - 双面胶、绝缘胶带

2. 后续外壳
   推荐：
   - 3D 打印 PLA / PETG
   - Fusion 360 / FreeCAD 建模

八、连接与焊接工具

1. 基础焊接工具
   推荐：
   - 可调温电烙铁
   - 0.6mm 或 0.8mm 焊锡丝
   - 助焊剂
   - 吸锡带
   - 镊子

2. 测试工具
   推荐：
   - 万用表
   - USB 电流电压表
   - 逻辑分析仪，8 通道 24MHz

   建议：
   逻辑分析仪对调 SPI 屏、SD 卡、I2S 音频很有帮助。

九、推荐第一批购买清单

如果只买第一批，建议先买这些：

1. WeAct Studio STM32H743VIT6 Core Board 或 NUCLEO-H743ZI2
2. ILI9341 2.8 英寸 320x240 SPI TFT 模块
3. SPI microSD Card Module，3.3V
4. SanDisk / Samsung 16GB microSD 卡
5. 6x6mm 轻触开关若干
6. 杜邦线套装
7. 面包板或洞洞板
8. MAX98357A I2S 功放模块
9. 8 欧 1W 小喇叭
10. 万用表
11. ST-Link 调试器，若开发板不自带调试器

十、暂时不建议第一版购买

1. STM32H750 裸芯片
   原因：内部 Flash 小，通常需要外部 QSPI Flash，第一版复杂度高。

2. 裸屏 FPC 屏幕
   原因：需要转接板和背光电路，调试难度比模块屏高。

3. 自定义锂电池保护/充电电路元件
   原因：电池安全风险高，第一版建议用成熟模块。

4. 自定义 PCB 打样
   原因：应先完成桌面原型，确认屏幕、SD 卡、按键、音频和模拟器都跑通。
